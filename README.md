# LAELia: Homeowners, Renters, Landlord, Dwelling and Flood claims

Demo instance of the LAELia claim tracker for personal property lines.

- Frontend: React + Vite (`sourceCode/apps/frontEnd`)
- API: Express + Apollo GraphQL (`sourceCode/apps/api`)
- Database: MongoDB Atlas
- Hosting: Netlify (static frontend + one Netlify Function for the API)

Status: initial clean import from the original LAELia code. Conversion to the five property lines is in progress; see `docs/`.
